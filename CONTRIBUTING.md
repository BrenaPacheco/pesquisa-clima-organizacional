# Como contribuir

1. Abra uma issue descrevendo a melhoria.
2. Crie uma branch com nome objetivo (`feature/nova-dimensao`).
3. Não adicione dados reais, identificadores, credenciais ou URLs privadas.
4. Execute `npm test` e revise a documentação.
5. Envie um pull request com descrição, testes e riscos de privacidade.

Mudanças nas perguntas ou método de pontuação devem atualizar `docs/METODOLOGIA.md`.
