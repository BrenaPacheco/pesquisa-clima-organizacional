# Segurança

**Não divulgue falhas envolvendo dados pessoais em issues públicas.** Contate reservadamente a equipe responsável pelo repositório via canal privado definido nos metadados do projeto. Não publique credenciais, IDs privados, dados brutos nem capturas com respostas reais.

O código é um exemplo para revisão, não um sistema auditado nem um mecanismo de garantia de anonimato.
